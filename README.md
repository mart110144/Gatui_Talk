# 💬 คุยกัน — เว็บบอร์ดเรียบง่าย (ไม่ต้องล็อกอิน)

เว็บบอร์ดที่ใครเข้ามาก็อ่าน ตั้งกระทู้ ตอบ และกดถูกใจได้ทันที
หน้าเว็บเป็น HTML/CSS/JS ล้วน (โฮสต์ฟรีบน GitHub Pages ได้) ส่วนข้อมูลเก็บใน **Supabase** (PostgreSQL ฟรี)

## โครงสร้างโปรเจกต์

```
webboard/
├── index.html              โครงหน้าเว็บ
├── css/
│   └── style.css           สไตล์เพิ่มเติม
├── js/
│   ├── config.js           ⭐ ตั้งค่า Supabase URL/Key, หมวดหมู่, ขีดจำกัด
│   ├── api.js              ติดต่อฐานข้อมูล (ที่เดียว)
│   ├── ui.js               สร้าง HTML / สลับหน้า / toast
│   ├── app.js              ตัวควบคุมหลัก: state, routing, events
│   ├── utils.js            ฟังก์ชันช่วย (escapeHtml, เวลาไทย, localStorage)
│   └── tailwind-config.js  ตั้งค่า Tailwind
├── database/
│   ├── schema.sql          สร้างตาราง + ความปลอดภัย (RLS)
│   └── seed.sql            (ไม่บังคับ) กระทู้ตัวอย่าง 4 กระทู้
└── README.md
```

## ขั้นตอนเชื่อมฐานข้อมูล (Supabase)

### 1) สร้างโปรเจกต์ Supabase
1. สมัคร/เข้าสู่ระบบที่ <https://supabase.com> แล้วกด **New project**
2. ตั้งชื่อโปรเจกต์, ตั้งรหัสผ่านฐานข้อมูล (เก็บไว้), เลือก Region ที่ใกล้ไทย (เช่น Singapore)
3. รอสักครู่จนโปรเจกต์พร้อมใช้งาน

### 2) สร้างตารางและระบบความปลอดภัย
1. เมนูซ้าย → **SQL Editor** → **New query**
2. เปิดไฟล์ `database/schema.sql` คัดลอกทั้งไฟล์มาวาง → กด **Run**
3. ต้องขึ้นว่า *Success* (รันซ้ำได้ ไม่พัง)

> อยากได้กระทู้ตัวอย่างไว้ลองก่อน: ทำแบบเดียวกันกับไฟล์ `database/seed.sql`

### 3) เอา URL และ Key มาใส่เว็บ
1. เมนูซ้าย → **Project Settings** → **API** (หรือ **API Keys**)
2. คัดลอก
   - **Project URL** (หน้าตา `https://xxxx.supabase.co`)
   - **anon / public key** (ในโปรเจกต์ใหม่อาจเรียก *Publishable key*)
3. เปิด `js/config.js` แล้วแทนค่า

```js
export const SUPABASE_URL = 'https://xxxx.supabase.co';
export const SUPABASE_ANON_KEY = 'ใส่คีย์ที่คัดลอกมา';
```

> ✅ anon/publishable key **เปิดเผยในโค้ดได้** เพราะความปลอดภัยคุมด้วย RLS ใน `schema.sql`
> ❌ **ห้าม** เอา `service_role` / secret key มาใส่ในโค้ดเว็บเด็ดขาด

### 4) ทดลองรันในเครื่อง
โปรเจกต์ใช้ ES Modules จึง **ดับเบิลคลิกเปิดไฟล์ตรงๆ ไม่ได้** ต้องเปิดผ่านเซิร์ฟเวอร์เล็กๆ อย่างใดอย่างหนึ่ง:

- VS Code → ติดตั้งส่วนเสริม **Live Server** → คลิกขวา `index.html` → *Open with Live Server*
- หรือใช้ Python ในโฟลเดอร์โปรเจกต์: `python -m http.server 8000` แล้วเปิด <http://localhost:8000>

ทดสอบ: ตั้งกระทู้ → รีเฟรช → กระทู้ต้องยังอยู่ → ลองเปิดจากอีกเครื่อง/เบราว์เซอร์ต้องเห็นเหมือนกัน

### 5) ขึ้นเว็บจริงด้วย GitHub Pages
1. อัปโหลดโฟลเดอร์โปรเจกต์ขึ้น GitHub repo (ไฟล์ `index.html` อยู่ราก repo)
2. Repo → **Settings** → **Pages** → Source: *Deploy from a branch* → เลือก `main` / `(root)` → Save
3. รอ 1–2 นาที จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/ชื่อ-repo/`

ลิงก์แต่ละกระทู้แชร์ได้ เช่น `…/#post=<id>`

## ความปลอดภัย (เพราะไม่มีระบบล็อกอิน)

สิ่งที่ `schema.sql` ทำให้แล้ว:

| เรื่อง | วิธีป้องกัน |
|---|---|
| คนแก้/ลบกระทู้คนอื่น | RLS อนุญาตแค่ *อ่าน* และ *เพิ่ม* — ไม่มี policy แก้/ลบ |
| ปั๊มไลก์ด้วยการแก้ตัวเลขตรงๆ | ผู้ใช้ไม่มีสิทธิ์ update ต้องผ่านฟังก์ชัน `like_post` (+1 ครั้งละหนึ่ง) |
| ส่งเวลา/ไลก์ปลอมตอนโพสต์ | จำกัดสิทธิ์ insert เฉพาะคอลัมน์ title, category, author, content |
| ข้อความยาวผิดปกติ / หมวดหมู่แปลก | check constraint ในตาราง (หัวข้อ ≤150, เนื้อหา ≤5,000, คอมเมนต์ ≤1,000) |
| XSS (ฝังสคริปต์ผ่านข้อความ) | ทุกข้อความผ่าน `escapeHtml()` ก่อนแสดง |

ฝั่งหน้าเว็บมี honeypot (ช่องซ่อนดักบอท) และหน่วงเวลาโพสต์ 15 วินาที — **แต่เป็นแค่ด่านเบา** คนที่เรียก API ตรงๆ ข้ามได้

### ข้อจำกัดที่ควรรู้
- **สแปมยังเป็นความเสี่ยงหลัก** ของเว็บที่ไม่มีล็อกอิน ถ้าเว็บเริ่มมีคนใช้เยอะ แนะนำเพิ่มทีหลัง:
  [Cloudflare Turnstile](https://www.cloudflare.com/products/turnstile/) (CAPTCHA ฟรี) หรือย้ายการโพสต์ไปผ่าน Supabase Edge Function ที่จำกัดจำนวนต่อ IP
- **การไลก์ 1 คนต่อ 1 กระทู้** บังคับแค่ในเบราว์เซอร์ (localStorage) คนที่ล้างข้อมูลเบราว์เซอร์หรือเรียก API ตรงๆ จะไลก์ซ้ำได้
- หน้ารวมโหลด **200 กระทู้ล่าสุด** (แก้ได้ที่ `POST_FETCH_LIMIT` ใน `config.js`) การค้นหา/เรียงลำดับทำในเบราว์เซอร์จากชุดนี้ ถ้ากระทู้เกินหลักพัน ควรย้ายไปค้นหาฝั่งฐานข้อมูล
- Supabase แพ็กเกจฟรี **จะพักโปรเจกต์ถ้าไม่มีการใช้งานราว 1 สัปดาห์** (กด Restore ใน Dashboard แล้วใช้ต่อได้)

## การดูแลเว็บ (Moderation)

ลบกระทู้/คอมเมนต์ที่ไม่เหมาะสม: Supabase → **Table Editor** → ตาราง `posts` หรือ `comments` → เลือกแถว → ลบ
(ลบกระทู้ = คอมเมนต์ในกระทู้นั้นถูกลบตามอัตโนมัติ)

ลบด้วย SQL ก็ได้:
```sql
delete from public.posts where id = 'ใส่-uuid-ของกระทู้';
delete from public.comments where id = 'ใส่-uuid-ของคอมเมนต์';
```

## การปรับแต่ง

- **เพิ่ม/แก้หมวดหมู่:** แก้ `CATEGORIES` ใน `js/config.js` **และ** แก้รายชื่อใน `check (category in (...))` ของ `schema.sql` ให้ตรงกัน (ถ้าตารางสร้างไปแล้วให้รัน `alter table` ปรับ constraint)
- **ปรับขีดจำกัดความยาว / เวลารอโพสต์:** `LIMITS` และ `COOLDOWN_MS` ใน `config.js` (ถ้าแก้ความยาว ให้แก้ใน `schema.sql` ด้วย)

## แก้ปัญหาเบื้องต้น

| อาการ | สาเหตุที่พบบ่อย |
|---|---|
| ขึ้นแถบเหลือง "ยังไม่ได้เชื่อมต่อฐานข้อมูล" | ยังไม่ได้แก้ค่าใน `js/config.js` |
| หน้าว่าง / Console error `Failed to load module` | เปิดไฟล์ด้วยดับเบิลคลิก (`file://`) → ใช้ Live Server หรือ `python -m http.server` |
| "โหลดกระทู้ไม่สำเร็จ" | URL/Key ผิด, ยังไม่ได้รัน `schema.sql`, หรือโปรเจกต์ถูกพัก — ดูข้อความใน Console (F12) |
| โพสต์ไม่ได้ ขึ้น error 401/403 ใน Console | รัน `schema.sql` ไม่ครบ (policy / grant ขาด) → รันทั้งไฟล์ใหม่อีกครั้ง |
| กดถูกใจไม่ได้ | ยังไม่ได้สร้างฟังก์ชัน `like_post` / `unlike_post` → รัน `schema.sql` ใหม่ |
